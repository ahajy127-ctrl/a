# 🤖 ربات معامله‌گر هایپرلیکوئید (Hyperliquid Trading Bot v26)

### نسخه جدید ربات شما — حالا روی هایپرلیکوئید (صرافی غیرمتمرکز) با کیف پول Rabby

---

## 📌 این نسخه چطور به وجود آمد؟

ربات نوبیتکس v25 شما کامل و حرفه‌ای بود، اما معاملات واقعی‌اش به صرافی نوبیتکس وصل بود.
این نسخه **همان استراتژی، همان سیستم‌های حفاظتی و همان داشبورد** را دارد، با این تفاوت که:

- ✅ **معاملات واقعی روی هایپرلیکوئید (Hyperliquid)** انجام می‌شود — صرافی غیرمتمرکز پرقدرت
- ✅ **سرمایه شما در کیف پول Rabby** می‌ماند و ربات فقط با یک **Agent Wallet** معامله می‌کند
- ✅ **هیچ کلید اصلی‌ای به ربات داده نمی‌شود** — Agent فقط می‌تواند معامله کند و **هرگز نمی‌تواند برداشت کند** 🔒
- ✅ امضای معاملات با استاندارد EIP-712 (امنیت بلاکچین)
- ✅ استاپ‌لاس محافظ (Backstop) روی خود صرافی + استاپ نرم‌افزاری در ربات

## 🚀 نصب و راه‌اندازی (قدم به قدم)

### قدم ۱: آپلود فایل‌ها روی سرور
فایل‌های این پوشه را با WinSCP/FileZilla در `/root/hyperliquid-bot/` کپی کنید.

### قدم ۲: نصب خودکار
```bash
cd /root/hyperliquid-bot
chmod +x install.sh manage.sh setup_hyperliquid.py
./install.sh
```
کتابخانه‌ها نصب می‌شود و ۱۰ تست سلامت اجرا می‌شود.

### قدم ۳: راه‌اندازی Agent Wallet (مهمترین قدم)
```bash
./manage.sh setup
```
این اسکریپت:
1. یک **کلید Agent جدید** برای ربات می‌سازد
2. از شما **آدرس کیف پول Rabby (Master)** را می‌گیرد
3. فایل `.env` را کامل می‌کند
4. مراحل بعدی را به شما نشان می‌دهد

### قدم ۴: اتصال Rabby به هایپرلیکوئید و تایید Agent (یک بار)
1. برنامه **Rabby** را نصب کنید (rabby.io) — اگر ندارید
2. به **app.hyperliquid.xyz** بروید و **Connect Wallet → Rabby** را بزنید
3. **Deposit** بزنید و USDC واریز کنید
4. بروید به **Settings → API Wallets → Add API wallet**
5. **آدرس Agent** که اسکریپت نشان داد را پیست کنید و **Approve** بزنید
   (تایید با Rabby شما امضا می‌شود — فقط یک بار)

### قدم ۵: روشن کردن ربات
```bash
./manage.sh start
```
داشبورد: `http://IP-SERVER:8080`

## 🛡️ سیستم‌های حفاظتی (همانند نسخه نوبیتکس)

1. **محافظ سقوط (Crash Guard):** ریزش ۷٪ بیت‌کوین در ۷ روز → توقف ورودهای جدید
2. **سقف ضرر روزانه:** ضرر ۸٪ در روز → توقف تا فردا
3. **چک‌پوینت‌ها:** وین‌ریت زیر ۲۰٪ یا PF زیر ۰.۶ → توقف خودکار
4. **سیرکیت‌بریکر:** ۳ ضرر پیاپی → استراحت ۲ ساعته
5. **Kill-Switch:** دستور `/killswitch` در تلگرام یا دکمه داشبورد → بستن همه فوری
6. **استاپ محافظ روی صرافی (Backstop):** برای هر پوزیشن لایو، یک استاپ-لاس روی خود هایپرلیکوئید ثبت می‌شود تا اگر ربات از کار افتاد، پوزیشن محافظت شود
7. **فیلتر عمق اردربوک:** سفارش‌ها بیشتر از ۱۰٪ عمق بازار نمی‌شوند
8. **حداقل حجم:** سفارش‌های زیر ۱۰ دلار ثبت نمی‌شوند

## 📈 استراتژی (همان استراتژی v25)

- RSI اشباع خرید/فروش + مومنتوم + روند SMA + رژیم بازار (صعودی/نزولی/رنج/طوفانی)
- تایید چندتایم‌فریم (۴ ساعته و روزانه)
- فشار اردربوک + نسبت حجم + فاندینگ‌ریت هایپرلیکوئید
- جلسات بازار جهانی (آسیا/اروپا/آمریکا)
- یادگیری شبح (Shadow Learning) — ربات از سیگنال‌های ثبت‌شده درس می‌گیرد
- خروج هوشمند: برداشت پله‌ای ۴۰٪، نقد کردن ۵۰٪، قفل سود، حالت دونده
- مدیریت ریسک: اندازه پوزیشن با فرمول کلی، حداقل ۲٪ و حداکثر ۲۵٪ سرمایه درگیر

## 🧪 برنامه تست هفتگی (مثل قبل)

- **روز ۱–۳:** ربات در حالت `paper` (مجازی ۱۰۰ دلاری) — بدون هیچ ریسکی
- **روز ۴–۷:** به ۳ شاخص نگاه کنید (داشبورد یا تلگرام):
  - **وین‌ریت** بالای ۵۰٪
  - **پروفیت فاکتور** بالای ۱.۱
  - **حداکثر افت** زیر ۸٪
- **پایان هفته:** اگر شاخص‌ها خوب بود، از داشبورد به حالت `live` بروید

> ⚠️ برای امنیت بیشتر، هفته اول را می‌توانید روی **Testnet** اجرا کنید (`HL_TESTNET=true`) و با پول آزمایشی تمرین کنید.

## 🔧 تنظیمات فایل `.env`

```ini
MODE=paper                    # paper یا live
HL_TESTNET=false              # true = آزمایشی
HL_ACCOUNT_ADDRESS=0x...      # آدرس کیف پول Rabby شما
HL_AGENT_PRIVATE_KEY=0x...    # کلید Agent (توسط setup ساخته می‌شود)
TG_TOKEN=...                  # ربات تلگرام (اختیاری)
TG_CHAT=...                   # Chat ID (اختیاری)
DASH_PASS=...                 # رمز داشبورد
HL_USE_TRIGGER_SL=true        # استاپ محافظ روی صرافی
```

## ⚠️ نکات امنیتی مهم

- فایل `.env` را **هیچ‌وقت** در گیت‌هاب آپلود نکنید (حاوی کلید Agent است). حتماً در لیست `.gitignore` باشد.
- کلید Agent فقط قدرت معامله دارد و برداشت برایش غیرممکن است — حتی اگر لو برود، کسی نمی‌تواند پول شما را ببرد.
- از کلید Rabby خودتان (Master) در هیچ فایلی کپی نکنید.
- برای امنیت بیشتر، کیف پول Rabby را روی هاردوال یا تلگرام رسمی Rabby نگه دارید.
